Idea: Video Call Software Consulting

Scenario:
Key users and project managers sit together in an online meeting and discuss problems and questions about software. They verbalize their ideas and want to find solutions. Traditionally, they take notes and execute them afterwards, but many details are missing because the notes and the meeting context is lost.
How can we improve this process through:

- Live transcription of the discussion
- Lively shared websites will be session recorded through DOM interactions
- Additional context can be added upfront or meanwhile
  - e.g. send an email to an inbox with a dedicated subejct for a specific meeting upfront
  - E.g. dump notes or additional information into some chat
  - Connect an underlying github repository
  - Share reference links to it.

I want to reduce the cognitive load for the people and do not require them to remember all the details. Also I would think of the following feautures:

1. Clarification questions mid way through the meeting or answering open questions raised from participants
2. Create contextual technical action items for the next steps
3. Ideally, we can immediately have the code being fixed in real time
